# WhyTree — 김진현

날짜: 2026-10-28

## 집사이 — 입주부터 퇴거까지 임대인·임차인이 함께 쓰는 기록·소통 플랫폼

`[씨앗]` = 주황 상자: 씨앗(현재 기능) · `[아직 하지 않는 일]` = 초록 점선 상자: 아직 하지 않는 일 · `(부가적인 why)` = 점선 화살표: 부가적인 why

- 평화로운 임대차 관계 유지
  - 퇴거 시 원상복구 분쟁 예방
    - 흩어진 기록 탐색 단축
      - 한 집 기록 시간순 정리 `[씨앗]`
      - 카톡 대화 요약 업로드 `[아직 하지 않는 일]`
    - 입주 시점 원본 확보
      - 입주 상태 공동 기록 `[씨앗]`
      - 입주·퇴거 상태 비교 `[씨앗]`
      - AI 생활마모·감가상각 판독 `[아직 하지 않는 일]`
    - 권리 보호 `(부가적인 why)`
  - 거주 중 수리·계약 갈등 완화
    - 수리·보수 책임 명확화
      - AI 생활마모·감가상각 판독 `(부가적인 why)`
      - 수리업체 매칭 연결 `[아직 하지 않는 일]`
      - 배심원 평결 `[아직 하지 않는 일]`
      - 사실 중심 리포트 전달 `(부가적인 why)`
    - 감정 뺀 객관적 사실 전달
      - 배심원 평결 `(부가적인 why)`
      - 비공개 AI 사전 상담 `[씨앗]`
      - 사실 중심 리포트 전달 `[씨앗]`
    - 권리 보호 `[아직 하지 않는 일]`
      - 맞춤 권리 분석 `[아직 하지 않는 일]`

## 변환 메모

- 원본: `whytree-jinhyun.pptx` (슬라이드 1장). 노드 문구와 연결은 슬라이드의 상자와 화살표를 그대로 따랐다.
- 부모가 둘인 노드는 실선 화살표(가장 중요한 why)가 가는 부모 아래에 한 번 쓰고, 점선 화살표가 가는 부모 아래에는 이름과 `(부가적인 why)` 표시만 남겼다.
  - `AI 생활마모·감가상각 판독`: 실선 → `입주 시점 원본 확보`, 점선 → `수리·보수 책임 명확화`
  - `배심원 평결`: 실선 → `수리·보수 책임 명확화`, 점선 → `감정 뺀 객관적 사실 전달`
  - `사실 중심 리포트 전달`: 실선 → `감정 뺀 객관적 사실 전달`, 점선 → `수리·보수 책임 명확화`
  - `권리 보호`: 실선 → `거주 중 수리·계약 갈등 완화`, 점선 → `퇴거 시 원상복구 분쟁 예방`
- 같은 부모 아래 순서는 슬라이드의 왼쪽→오른쪽 순서를 따랐다.
