# WhyTree — 조현지

날짜: 2026-10-29

## 집사이 WhyTree

`[씨앗]` = 기존 SEED(현재 기능) · `[아직 하지 않는 일]` = 새 HOW: 아직 하지 않는 일

- 주거 문제를 걱정 없이 해결하는 생활
  - 빠른 주거 문제 해결
    - 문제 상황의 정확한 파악
      - 주거 문제 기록 `[씨앗]`
      - 증상별 첫 행동 가이드 `[아직 하지 않는 일]`
      - 집 관리 Q&A 커뮤니티 `[아직 하지 않는 일]`
    - 상대방에게 명확한 상황 전달
      - AI 비공개 상담 및 리포트 `[씨앗]`
      - 집주인 연락문 작성 도우미 `[아직 하지 않는 일]`
    - 수리 과정의 투명한 확인
      - 수리 처리 이력 관리 `[씨앗]`
      - 수리 진행 상태 추적 `[아직 하지 않는 일]`
  - 불필요한 분쟁 예방
    - 입주 당시 상태의 객관적 기록
      - 입주 상태 사진 기록 `[씨앗]`
      - 표준 촬영 가이드 `[아직 하지 않는 일]`
    - 양측의 사실 인식 차이 축소
      - 임대인·임차인 공동 확인 `[씨앗]`
      - 미응답 포함 확인 이력 `[아직 하지 않는 일]`
