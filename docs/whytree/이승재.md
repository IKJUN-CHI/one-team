# WhyTree — 집사이 (집 관리 플랫폼)

- 이름: 이승재
- 날짜: 2026-10-29
- 슬라이드: WhyTree-집사이.pptx (2번 슬라이드)

## 읽는 법

- 위가 why(목적), 들여쓴 아래가 how(방법)입니다. 슬라이드의 화살표는 아래(how)에서 위(why)로 향합니다.
- `[씨앗]` = 노란 상자, 지금 집사이가 하는 일
- `[새 방법]` = 점선 상자, 아직 하지 않는 일
- 표시 없음 = 실선 상자
- `(점선 화살표: 부가적인 why)` = how 하나가 다른 why에도 도움이 되는 경우

## 트리

- 집주인·세입자가 집 문제 걱정 없이 지내기
  - 보증금·수리비 다툼 줄이기
    - 집 상태 증거 남기기
      - 입주 상태 사진 기록 [씨앗]
      - 퇴거 때 입주 상태와 비교 [씨앗]
      - AI 사진 하자 표시 [새 방법]
    - 합의 내용 믿기
      - 원본·변경 이력 보관 [씨앗]
      - 사실 중심 리포트 전송 [씨앗] (점선 화살표: 부가적인 why)
  - 집 문제 빨리 해결하기
    - 상대에게 정확히 전달하기
      - 사실 중심 리포트 전송 [씨앗]
    - 감정 빼고 문제 정리하기
      - AI 비공개 상담 [씨앗]
    - 수리업체 바로 연결 [새 방법]
    - 관리사무소 요청 창구 [새 방법]
  - 여러 집 관리 부담 줄이기 [새 방법]
    - 집별 수리 이력 한눈에 보기 [새 방법]

## 슬라이드 메모

노란 상자는 지금 집사이가 하는 일 다섯 가지(씨앗), 점선 상자는 교수님 피드백을 반영해 새로 찾은 방법입니다. "사실 중심 리포트 전송"의 가장 중요한 why는 "상대에게 정확히 전달하기"라서 실선, "합의 내용 믿기"에도 도움이 되므로 점선으로 이었습니다.
