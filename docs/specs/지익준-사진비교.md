## 3. 사용 장면

오피스텔 관리사무소 직원이 퇴실 점검을 할 때, 입주 때 찍은 사진과 지금 상태를 나란히 놓고 본다.
화면에는 임대인이나 임차인 중 누구 편을 드는 문구를 넣지 않는다. 두 사진을 나란히 보여 주기만 한다.

## 4. 만드는 방식

- 파일 하나로 된 웹페이지다: `prototypes/지익준/index.html`. 컴퓨터에서 이 파일을 더블클릭하면 인터넷 창(크롬, 엣지 등)에서 바로 열린다. 따로 설치하거나 설정할 것은 없다.
- 휴대폰에서 열려면 이 파일을 휴대폰으로 옮기거나 인터넷에 올려야 해서, 이번에는 컴퓨터에서 여는 것을 기준으로 한다. 다만 화면이 좁으면 배치가 바뀌도록 만들어 두었다(5.3).
- 서버(인터넷 저장소)를 쓰지 않는다. 로그인도 없다. 올린 사진은 그 기기 밖으로 나가지 않는다.
- **AI 모델은 사용하지 않는다.** 사진 짝짓기와 비교는 모두 사람이 직접 한다.
- AI를 쓰지 않으므로 AI가 실패하는 상황은 없다.

## 5. P0 — 반드시 만드는 것

### 5.1 사용자가 할 수 있는 일 (순서대로)

1. 웹페이지를 연다. "예시 (연습·시연용 그림)" 칸에 **예시 3쌍**이 좌우로 나란히 보인다.
   - 예시는 사진 대신 단순한 그림이다. 방 · 벽(얼룩), 주방 · 설비(긁힘), 욕실 · 바닥(금).
   - 연습과 시연용이라 차이가 잘 보이게 만들었다.
   - 예시는 "올린 사진" 칸과 따로 있다. 같은 위치(예: 방 · 벽)에 사진을 올려도 예시는 바뀌지 않는다.
2. "사진 올리기" 칸에서 **파일 선택**을 눌러 사진을 하나 고른다.
3. 그 사진이 **입주**인지 **퇴실**인지 고른다. 처음에는 "입주"가 골라져 있다.
4. 그 사진의 **위치**를 목록에서 고른다(공간 하나 + 부위 하나). 처음에는 "현관"과 "벽"이 골라져 있다.
5. **올리기** 버튼을 누른다.
   - 버튼 아래에 "방 · 바닥 입주 사진을 올렸습니다."처럼 결과가 나온다.
   - "올린 사진" 칸에 그 위치의 줄이 생긴다. 반대쪽 사진이 아직 없으면 그 칸에 "퇴실 사진 없음"처럼 표시된다.
6. 같은 위치를 골라 반대쪽(입주 또는 퇴실) 사진을 2~5번과 같은 순서로 올린다.
7. 같은 위치의 두 사진이 **한 줄에 좌우로 나란히** 나온다(왼쪽 입주, 오른쪽 퇴실).
8. 사진을 누르면 **그 사진만 크게** 열린다. 아래에 "퇴실 · 방 · 벽"처럼 어떤 사진인지 적혀 있다.
   - **닫기** 버튼, 사진 바깥의 어두운 곳 누르기, 키보드 **Esc** 중 아무것으로나 닫을 수 있다. 닫으면 원래 화면으로 돌아온다.
9. 찾은 차이는 화면이 아니라 **종이나 메모장에 따로** 적는다.

### 5.2 위치 목록 (고정)

| 공간 | 부위 |
|---|---|
| 현관 / 방 / 주방 / 욕실 / 베란다·창가 | 벽 / 바닥 / 천장 / 문·창문 / 설비(싱크대, 변기, 에어컨 등) |

직접 입력하는 칸은 없다. 고르는 목록에는 괄호 안의 예시 없이 "설비"라고만 나온다.

### 5.3 화면 규칙

- 위치마다 입주 사진 1장, 퇴실 사진 1장만 받는다. 같은 칸에 다시 올리면 새 사진으로 바꿔 끼우고, "…사진을 바꿔 넣었습니다."라고 알려 준다.
- 한쪽 사진이 없으면 빈칸에 "입주 사진 없음" 또는 "퇴실 사진 없음"이라고 표시한다.
- 아직 올린 사진이 하나도 없으면 "올린 사진" 칸에 "아직 올린 사진이 없습니다."라고 표시한다.
- "올린 사진" 칸의 줄은 올린 순서가 아니라 위치 목록 순서(현관 → 방 → … , 벽 → 바닥 → …)로 놓인다.
- 각 줄의 제목은 "방 · 바닥"처럼 "공간 · 부위"로 쓴다.
- 화면 너비가 600픽셀 이하이면(휴대폰 정도) 좌우 대신 위아래로 놓는다.
- 사진 파일만 고를 수 있다. 사진을 고르지 않고 올리기를 누르면 "먼저 사진을 골라 주세요.", 사진이 아닌 파일이면 "사진 파일만 올릴 수 있습니다."라고 알려 준다.
- 올리기가 끝나면 파일 선택 칸이 비워져서 다음 사진을 바로 고를 수 있다.
- 창을 닫거나 새로고침하면 올린 사진이 사라진다.
  - 페이지 위쪽에 "창을 닫거나 새로고침하면 올린 사진이 사라집니다. 사진은 이 기기 밖으로 보내지지 않습니다."라는 안내를 늘 띄운다.
  - 사진을 하나라도 올린 뒤 창을 닫거나 새로고침하려 하면, 인터넷 창이 "나가시겠습니까?"처럼 한 번 묻는다. 묻는 문구는 인터넷 창마다 조금씩 다르다. 올린 사진이 없으면 묻지 않는다.
- 실험용 사진은 페이지 안에 넣지 않는다. 실험할 때 직접 올린다(정답이 미리 새지 않게 하려는 것이다).

### 5.4 만들지 않는 것 (이번 범위 밖)

- 찾은 차이를 화면에 표시하거나 기록하는 기능
- 사진 보관(창을 닫은 뒤에도 남기기)
- 자동으로 같은 장소를 찾거나 차이를 찾아 주는 기능

## 7. P2 — 나중에 할 것

- **겹쳐 보기 슬라이더**: 두 사진을 겹쳐 놓고 가운데 막대를 밀어 가며 차이를 본다.
- **동시 확대**: 한쪽을 확대하면 다른 쪽도 같은 자리가 똑같이 확대된다.
- **예시 그림을 실제 사진으로 교체**
- **현장에서 휴대폰으로 열 수 있게 인터넷에 올리기** (퇴실 점검은 보통 휴대폰으로 하기 때문)
- **실험 진행**:
  - 사진 세트: 직접 찍은 사진 8쌍. 이 중 2쌍은 흔적 없이 조명과 각도만 바꾼다(없는 차이를 있다고 하는 "헛짚기"를 보기 위함).
  - 일부러 만든 흔적: 모두 10개(큰 것 3, 중간 4, 작은 것 3). 예: 마스킹테이프, 지워지는 펜 자국, 물건 위치 바꾸기. 정답표는 지익준만 가진다.
  - 퇴실 사진 찍는 법: 다른 시간대에, 손으로 들고, 반 걸음쯤 다른 자리에서 찍는다.
  - 참가자: 팀원이나 지인 3~5명. 흔적이 몇 개인지 알려 주지 않는다.
  - 시간 제한은 두지 않는다. 걸린 시간만 종이에 적는다.
  - 성공 기준(가설적 기준): 참가자 평균으로 흔적 10개 중 7개 이상을 찾고 헛짚기가 1번 이하다.
    - 성공하면: 자동 비교는 만들지 않고 나란히 보기에 집중한다.
    - 실패하면: 어떤 흔적을 놓쳤는지(작아서? 조명 때문에?) 살펴본 뒤, 촬영 가이드("같은 자리에서, 불 켜고 찍기")를 붙여 다시 시험한다.
- **기존 방식과 비교하는 실험**: 사진첩을 넘겨 보는 방식과 이 도구를 비교한다.
- **실제 관리사무소 직원 참여 실험**
